# unirg14-marcadores-tumorales-estomago
##Proyecto del master bioinformatica del grupo 14

El cáncer gástrico representa una de las neoplasias más prevalentes y con alta tasa de mortalidad a nivel global. 
El objetivo principal es identificar paneles de genes expresados que sirvan como biomarcadores y la predicción de respuesta clínica.

Realizamos una estructura de carpetas para organizar esta simulacion de proyecto con diferentes archivos. Se crearon ramas de trabajo 
individuales para cada integrante, permitiendo el desarrollo y la prueba aislada de cada componente sin comprometer la rama principal.
Se realizaron varios commits y se consolidaron los aportes individuales.
