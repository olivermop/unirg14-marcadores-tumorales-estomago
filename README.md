# unirg14-marcadores-tumorales-estomago
Proyecto del master bioinformatica del grupo 14 















## Análisis Estadístico

En este repositorio encontrarás los códigos de R para el análisis estadístico.

### Supervivencia
Se creo el códgio para Curvas de Kaplan Meyer y Hazard Ratios para los pacientes, separados según marcador tumoral positivo.

### Módelo - Machine Learning
Se creó modelos de Regresión Logística calculando las razones de probabilidad (OR) no ajustado y ajustado dependiendo de cada marcador tumoral.
